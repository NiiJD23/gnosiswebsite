# Gnosis website

The product website for [Gnosis](https://github.com/NiiJD23/gnosisv2), a private, local-first personal AI assistant.

Live at https://gnosis.promintal.com

## What is here

- `index.html`: the whole site in one file (styles, script and screenshots included)
- `favicon.svg`: the Gnosis logo mark
- `downloads/`: the Mac app and the full package that the download buttons link to

## Publish

Point Cloudflare Pages at this repository with no build command and `/` as the output folder, then set the custom domain to `gnosis.promintal.com`.
